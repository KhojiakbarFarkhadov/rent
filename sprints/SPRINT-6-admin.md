# SPRINT 6 — admin

**Maqsad:** platformani kod yozmasdan boshqarish — e'lon va bron tasdig'i, egalar nazorati, statistika.

**Savol:** Boshqarib bo'ladimi?

## Tasklar

- [ ] Admin paneli: e'lon so'rovlari va bron so'rovlari bitta navbatda, qidiruv va filtr bilan
- [ ] E'lonni joylash, tahrirlash, tasdiqlash va rad etish
- [ ] Bron so'rovini tasdiqlash va rad etish ekrani (sababi bilan)
- [ ] Egani tasdiqlash va bloklash — hujjatni ko'rish faqat admin uchun
- [ ] Statistika: haftalik bron soni, aylanma, ushlangan komissiya, eng ko'p bron qilingan turkum
- [ ] Qo'lda tuzatish: admin bron holatini va sanasini o'zgartira olishi
- [ ] Egalarni qo'lda kiritish: birinchi tanish egalarni admin o'zi qo'shadi

## Qabul mezoni

- Admin panelida yangi e'lon so'rovi ko'rinadi va tasdiqlangach katalogga chiqadi
- Rad etilgan bronda mijozga sabab ko'rinadi
- Bloklangan ega yangi so'rov yubora olmaydi
- Statistika sahifasida shu haftadagi bron soni va komissiya summasi chiqadi
- Admin bron sanasini o'zgartirsa, bandlik hisobi ham yangilanadi
